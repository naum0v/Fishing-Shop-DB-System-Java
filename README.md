# Fishing-Shop-DB-System-Java
Клиент-серверная информационная система для автоматизации рыболовного магазина (PostgreSQL + Java Swing)

# Информационная система «Рыболовный магазин»

Курсовая работа по дисциплине «Базы данных». Проект представляет собой полноценную клиент-серверную информационную систему для автоматизации учета товаров, заказов, работы с поставщиками и ведения программы лояльности рыболовного магазина.

## Особенности архитектуры

- **Серверная часть (PostgreSQL):** Разработана структура из 10 таблиц, приведенных к нормальной форме Бойса-Кодда (БКНФ). Вся бизнес-логика вынесена на уровень СУБД: реализовано 32 хранимые процедуры и функции, 3 триггера и 6 представлений. Прямой доступ клиента к таблицам БД закрыт.
- **Клиентская часть (Java):** Настольное приложение с графическим интерфейсом на базе библиотеки Swing. Взаимодействие с базой данных реализовано через паттерн DAO (Data Access Object) путем вызова хранимых процедур.
- **Развертывание:** База данных разворачивается в изолированном Docker-контейнере. Настроен автоматический запуск SQL-скриптов при первом старте контейнера (Docker Compose). Для установки клиентского приложения используется инсталлятор Inno Setup.

## Технологии

*   **PostgreSQL 15**
*   **Java (JDK 17, Swing)**
*   **Docker / Docker Compose**
*   **Inno Setup**

## Структура проекта

*   `src/` — исходный код клиентского приложения на Java (пакеты `dao`, `model`, `ui`).
*   `sql/` — SQL-скрипты для создания таблиц, наполнения данными, создания процедур, триггеров и представлений.
*   `deploy/` — конфигурационные файлы Docker (`docker-compose.yml`), скрипты запуска (`.bat`) и собранный `.jar` файл приложения.
*   `lib/` — внешние библиотеки (драйвер PostgreSQL).
*   `docs/` — пояснительная записка (PDF) и ER-диаграмма.
